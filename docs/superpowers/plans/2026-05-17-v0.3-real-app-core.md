# V0.3 — Real App Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `overflow: hidden` clipping, `on_scroll` event dispatch, a `Scroll` viewport widget, a `TextFieldState` data type, and a `TextInput` widget — enabling the first real form-like UI in Lemon.

**Architecture:** `Overflow::Hidden` is a paint-only concern: the layout pass (Taffy) is unaffected; the paint pass wraps children in a Vello clip layer when the flag is set. `Scroll` is a pure builder in `lemon-widgets` — the user owns a `Signal<f64>` offset and passes it in; `Scroll` emits the viewport Box_ with `on_scroll` and the inner content Box_ with negative `margin_top`. `TextInput` is also a pure builder that takes `Signal<TextFieldState>` plus `Signal<bool>` for focus tracking; keyboard routing uses the V0.2 `FocusManager`. Click-to-focus (setting `FocusManager.focused` on click of a focusable node) is wired in this milestone.

**Tech Stack:** Rust, winit 0.30 (MouseWheel events), Taffy 0.7 (margin_top for scroll offset), Vello 0.9 (push_layer/pop_layer for clipping), lemon-widgets crate (Scroll, TextInput builders).

**Pre-requisite:** V0.2 complete. The following are already in place:
- `EventHandlers`: `on_click`, `on_key_down`, `on_key_up`, `on_hover_enter`, `on_hover_leave`
- `BoxElement.handlers: EventHandlers`
- `StyleProps`: `focusable: bool`, `cursor: Cursor`
- `FocusManager` with `focused: Option<NodeId>`, `cycle(tree, forward)`, `focus_by_id(id, tree)`
- Container builders: `.on_click()`, `.on_key_down()`, `.on_key_up()`, `.on_hover_enter()`, `.on_hover_leave()`, `.focusable()`
- `KeyEvent`, `LemonKey`, `NamedKey`, `Modifiers` exported from `lemon`
- `AppState`: `focus_manager: FocusManager`, `hovered_node_id: Option<NodeId>`
- Platform dispatches keyboard to `focus_manager.focused` node

```rust
/// Walk the retained tree in post-order and return the top-most node under
/// `point` that has an `on_scroll` handler.
pub fn hit_test_scroll<'a>(
    node: &'a RetainedNode,
    layout: &LayoutMap,
    point: LogicalPoint,
) -> Option<&'a RetainedNode> {
    if matches!(node.kind, RetainedKind::Component { .. }) {
        let mut hit = None;
        for child in &node.children {
            hit = hit_test_scroll(child, layout, point).or(hit);
        }
        return hit;
    }

    let mut hit = None;
    for child in &node.children {
        hit = hit_test_scroll(child, layout, point).or(hit);
    }

    if node.handlers.on_scroll.is_some() {
        if let Some(id) = node.taffy_id {
            if let Some(rect) = layout.get(id) {
                if point_in_rect(point, rect) {
                    hit = Some(node);
                }
            }
        }
    }

    hit
}
```

```rust
WindowEvent::MouseWheel { delta, .. } => {
    let (px, py) = self.last_cursor.unwrap_or((0.0, 0.0));
    let logical = self.cursor_logical(f64::from(px), f64::from(py));
    let delta_y = match delta {
        MouseScrollDelta::LineDelta(_, y) => f64::from(y) * 20.0,
        MouseScrollDelta::PixelDelta(pos) => pos.y,
    };
    // Positive delta_y = scroll down (content moves up = offset increases).
    self.event_pass_scroll(logical, -delta_y);
}
```

> **Note:** winit's `LineDelta.y` is positive when scrolling up (away from user), so we negate the result so that "scroll down physically" → positive delta passed to handlers → offset increases → content moves up.

```rust
    let Some(tree) = self.retained.as_ref() else { return false; };
    let Some(root) = tree.root.as_ref() else { return false; };

    if let Some(focused_node) = hit_test_focusable(root, &self.layout_map, point) {
        if let Some(id) = focused_node.taffy_id {
            self.focus_manager.focused = Some(id);
        }

        return false;

        return false;

    if handled {
```

> **Note:** We borrow `retained` twice. To avoid the borrow checker issue, extract focusable hit-test result before the second borrow, or restructure using an early clone of the taffy_id. Simplest fix:

```rust
fn event_pass_click(&mut self, point: LogicalPoint) -> bool {
    // Phase 1: find focusable node under click, update focus.
    let focusable_id = self.retained
        .as_ref()
        .and_then(|t| t.root.as_ref())
        .and_then(|root| hit_test_focusable(root, &self.layout_map, point))
        .and_then(|node| node.taffy_id);

    if let Some(id) = focusable_id {
        self.focus_manager.focused = Some(id);
        self.paint_dirty = true;
    }

    // Phase 2: dispatch on_click.
```

```rust
pub struct Scroll {

    offset: Signal<f64>,
    height: f32,
    width: Option<f32>,
}

impl Scroll {
    pub fn new(child: impl Into<Element>, offset: Signal<f64>) -> Self {
        Scroll {
            child: child.into(),
            offset,
            height: 200.0,
            width: None,
        }
    }

    pub fn height(mut self, h: f32) -> Self {
        self.height = h;
        self
    }

    pub fn width(mut self, w: f32) -> Self {
        self.width = Some(w);
        self
    }

    pub fn into_element(self) -> Element {
        let offset_val = self.offset.get() as f32;
        let off = self.offset.clone();

        let mut viewport = Box_::new()
            .height(self.height)
            .overflow(Overflow::Hidden)
            .on_scroll(move |delta| {
                let new_val = (off.get() + delta).max(0.0);
                off.set(new_val);
            });

        if let Some(w) = self.width {
            viewport = viewport.width(w);
        }

        viewport
            .child(
                Box_::new()
                    .margin_top(-offset_val)
                    .child(self.child)
            )
            .into_element()
    }
}

impl From<Scroll> for Element {
    fn from(s: Scroll) -> Self {
        s.into_element()
    }
```

```rust
use lemon::{KeyEvent, KeyState, LemonKey, Modifiers, NamedKey};

#[derive(Clone, Debug, Default, PartialEq)]
pub struct TextFieldState {
    pub value: String,
    pub cursor: usize, // byte offset into `value`
}

impl TextFieldState {
    pub fn new(initial: impl Into<String>) -> Self {
        TextFieldState {
            value: initial.into(),
            cursor: 0,
        }
    }

    pub fn handle_key(&mut self, event: &KeyEvent) {
        if event.state == KeyState::Released {
            return;
        }
        match &event.key {
            LemonKey::Character(c) if !event.modifiers.ctrl => {
                for ch in c.chars() {
                    self.value.insert(self.cursor, ch);
                    self.cursor += ch.len_utf8();
                }
            }
            LemonKey::Named(NamedKey::Backspace) => {
                if self.cursor > 0 {
                    let prev = self.prev_char_boundary(self.cursor);
                    self.value.remove(prev);
                    self.cursor = prev;
                }
            }
            LemonKey::Named(NamedKey::Delete) => {
                if self.cursor < self.value.len() {
                    self.value.remove(self.cursor);
                }
            }
            LemonKey::Named(NamedKey::ArrowLeft) => {
                if self.cursor > 0 {
                    self.cursor = self.prev_char_boundary(self.cursor);
                }
            }
            LemonKey::Named(NamedKey::ArrowRight) => {
                if self.cursor < self.value.len() {
                    self.cursor = self.next_char_boundary(self.cursor);
                }
            }
            LemonKey::Named(NamedKey::Home) => {
                self.cursor = 0;
            }
            LemonKey::Named(NamedKey::End) => {
                self.cursor = self.value.len();
            }
            _ => {}
        }
    }

    fn prev_char_boundary(&self, pos: usize) -> usize {
        let mut p = pos.saturating_sub(1);
        while p > 0 && !self.value.is_char_boundary(p) {
            p -= 1;
        }
        p
    }

    fn next_char_boundary(&self, pos: usize) -> usize {
        let mut p = pos + 1;
        while p < self.value.len() && !self.value.is_char_boundary(p) {
            p += 1;
        }
        p.min(self.value.len())
    }
}
```

```rust
use std::rc::Rc;
use lemon::{
    Color,
    element::Element,
    element::builders::{Box_, Text},
    element::events::Cursor,
    runtime::signal::Signal,
};
use crate::text_field_state::TextFieldState;

pub struct TextInput {
    state: Signal<TextFieldState>,
    focused: Signal<bool>,
    placeholder: String,
    width: Option<f32>,
}

impl TextInput {
    pub fn new(state: Signal<TextFieldState>, focused: Signal<bool>) -> Self {
        TextInput {
            state,
            focused,
            placeholder: String::new(),
            width: None,
        }
    }

    pub fn placeholder(mut self, text: &str) -> Self {
        self.placeholder = text.to_string();
        self
    }

    pub fn width(mut self, w: f32) -> Self {
        self.width = Some(w);
        self
    }

    pub fn into_element(self) -> Element {
        let state_val = self.state.get();
        let is_focused = self.focused.get();

        let border_color = if is_focused {
            Color::rgb8(80, 130, 230)
        } else {
            Color::rgb8(90, 90, 110)
        };

        let state = self.state.clone();
        let focused = self.focused.clone();

        let text_child: Element = if state_val.value.is_empty() {
            Text::new(self.placeholder)
                .color(Color::rgb8(90, 90, 110))
                .into_element()
        } else {
            Text::new(state_val.value).into_element()
        };

        let mut outer = Box_::new()
            .focusable()
            .padding(8.0)
            .border(border_color, 1.5)
            .radius(4.0)
            .cursor(Cursor::Text)
            .on_click(move || {
                focused.set(true);
            })
            .on_key_down(move |event| {
                let mut s = state.get();
                s.handle_key(&event);
                state.set(s);
            })
            .child(text_child);

        if let Some(w) = self.width {
            outer = outer.width(w);
        }

        outer.into_element()
    }
}

impl From<TextInput> for Element {
    fn from(t: TextInput) -> Self {
        t.into_element()
    }
}
```
