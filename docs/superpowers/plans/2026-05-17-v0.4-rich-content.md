# V0.4 — Rich Content Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add image rendering, z-index paint ordering, a draggable `Slider`, a `Select` dropdown, and a scrollbar visual — making Lemon capable of real data-display UIs.

**Architecture:** Images are decoded by the `image` crate into RGBA8 pixels stored in `Arc<ImageData>`; paint renders them via `vello::peniko::Image` with object-fit:contain scaling. Z-index is a paint-only concern: a two-pass approach collects deferred nodes during the normal traversal, then paints them sorted by z_index. `Select` and `Slider` are pure builders that take user-owned `Signal<T>` state; pointer drag uses a new `on_pointer_down` / `on_pointer_move` handler pair where the platform normalizes cursor position to the node's rect (0.0..1.0 fraction), and `mouse_capture_node` in `AppState` holds focus through the gesture. `Select` uses `on_click_outside` to close its dropdown.

**Tech Stack:** Rust, `image 0.25` (PNG/JPEG decode), Vello 0.9 + peniko (`draw_image`), Taffy 0.7 (z_index is paint-only, layout unchanged), lemon-widgets crate.

**Pre-requisites:** V0.3 complete. The following are already in place:
- `EventHandlers`: `on_click`, `on_key_down`, `on_key_up`, `on_hover_enter`, `on_hover_leave`, `on_scroll`
- `StyleProps`: `focusable`, `cursor`, `overflow`, and margin/padding/flex fields
- `AppState`: `focus_manager: FocusManager`, `hovered_node_id`, `active_modifiers`, `last_cursor`
- `find_node_by_taffy_id` in `platform/hit_test.rs`
- `Scroll`, `TextInput`, `TextFieldState` in `lemon-widgets`
- Container builders: `.on_click()`, `.on_key_down()`, `.on_scroll()`, `.overflow()`, `.margin_top()`

```rust
fn paint_image(
    node: &RetainedNode,
    rect: &LayoutRect,
    scene: &mut Scene,
    ctx: PaintContext,
) {
    let Some(handle) = &node.paint.image else {
        return;
    };
    if rect.width <= 0.0 || rect.height <= 0.0 {
        return;
    }

    let img_w = handle.width() as f32;
    let img_h = handle.height() as f32;
    if img_w <= 0.0 || img_h <= 0.0 {
        return;
    }

    // object-fit: contain — scale uniformly to fit in rect, centered.
    let scale = (rect.width / img_w).min(rect.height / img_h);
    let draw_w = img_w * scale;
    let draw_h = img_h * scale;
    let ox = rect.x + (rect.width - draw_w) * 0.5;
    let oy = rect.y + (rect.height - draw_h) * 0.5;

    let transform = ctx.base
        * Affine::translate((f64::from(ox), f64::from(oy)))
        * Affine::scale(f64::from(scale));

    let blob = Blob::from(handle.pixels().to_vec());
    let peniko_img = PenikoImage::new(blob, ImageFormat::Rgba8, handle.width(), handle.height());

    scene.draw_image(&peniko_img, transform);
}
```

- [ ] **Step 4.5: Implement two-pass z_index ordering in `paint_pass`**

In `crates/lemon/src/paint/mod.rs`, restructure `paint_pass` and `paint_node` to use a deferred list:

Replace the current `paint_pass` and add a new inner function:

```rust
pub fn paint_pass(
    tree: &RetainedTree,
    layout: &LayoutMap,
    scene: &mut Scene,
    scale_factor: f32,
) -> PaintStats {
    let mut stats = PaintStats::default();
    let base = if scale_factor == 1.0 {
        Affine::IDENTITY
    } else {
        Affine::scale(f64::from(scale_factor))
    };
    let ctx = PaintContext { base };

    scene.push_layer(
        Fill::NonZero,
        BlendMode::default(),
        1.0,
        base,
        &clip_everything(),
    );

    let mut deferred: Vec<(i32, *const RetainedNode)> = Vec::new();

    if let Some(root) = tree.root.as_ref() {
        paint_node_z(root, layout, scene, ctx, &mut stats, &mut deferred);
    }

    // Sort deferred by z_index ascending (lower z_index painted first = behind).
    deferred.sort_by_key(|(z, _)| *z);

    for (_, node_ptr) in deferred {
        // SAFETY: the retained tree is alive for the duration of paint_pass.
        let node = unsafe { &*node_ptr };
        paint_node(node, layout, scene, ctx, &mut stats);
    }

    scene.pop_layer();
    stats
}

/// Like `paint_node` but defers nodes with z_index != 0 to `deferred`.
fn paint_node_z(
    node: &RetainedNode,
    layout: &LayoutMap,
    scene: &mut Scene,
    ctx: PaintContext,
    stats: &mut PaintStats,
    deferred: &mut Vec<(i32, *const RetainedNode)>,
) {
    if matches!(node.kind, RetainedKind::Component { .. }) {
        for child in &node.children {
            paint_node_z(child, layout, scene, ctx, stats, deferred);
        }
        return;
    }

    let Some(taffy_id) = node.taffy_id else {
        for child in &node.children {
            paint_node_z(child, layout, scene, ctx, stats, deferred);
        }
        return;
    };

    if node.style.z_index != 0 {
        // Defer this node (with its subtree) to the z_index pass.
        deferred.push((node.style.z_index, node as *const RetainedNode));
        return;
    }

    let Some(rect) = layout.get(taffy_id) else {
        return;
    };

    paint_container(node, rect, scene, ctx, stats);
    paint_text(node, rect, scene, ctx, stats);
    paint_image(node, rect, scene, ctx);

    if node.style.overflow == Overflow::Hidden {
        let clip = Rect::new(
            f64::from(rect.x),
            f64::from(rect.y),
            f64::from(rect.x + rect.width),
            f64::from(rect.y + rect.height),
        );
        scene.push_layer(Fill::NonZero, BlendMode::default(), 1.0, ctx.base, &clip);
        for child in &node.children {
            paint_node_z(child, layout, scene, ctx, stats, deferred);
        }
        scene.pop_layer();
    } else {
        for child in &node.children {
            paint_node_z(child, layout, scene, ctx, stats, deferred);
        }
    }
}
```

> **Raw pointer note:** We use `*const RetainedNode` to avoid lifetime issues in the deferred vec. The `RetainedTree` borrow covers the entire `paint_pass` call, so the pointer is valid. If you prefer lifetimes, use `Vec<(i32, &'_ RetainedNode)>` with a `'_` lifetime tied to the tree borrow — the split-borrow makes this awkward, so the raw pointer is pragmatic here.

```rust
/// Find the topmost node with `on_pointer_down` under `point`.
/// Returns `(node, norm_x, norm_y)` where norm_x/y are in 0.0..=1.0 relative to the node's rect.
pub fn hit_test_pointer_down<'a>(
    node: &'a RetainedNode,
    layout: &LayoutMap,
    point: LogicalPoint,
) -> Option<(&'a RetainedNode, f32, f32)> {
    if matches!(node.kind, RetainedKind::Component { .. }) {
        for child in &node.children {
            if let Some(result) = hit_test_pointer_down(child, layout, point) {
                return Some(result);
            }
        }
        return None;
    }

    // Children first (post-order → deepest wins)
    for child in &node.children {
        if let Some(result) = hit_test_pointer_down(child, layout, point) {
            return Some(result);
        }
    }

    if node.handlers.on_pointer_down.is_some() {
        if let Some(id) = node.taffy_id {
            if let Some(rect) = layout.get(id) {
                if point_in_rect(point, rect) {
                    let norm_x = ((point.x - rect.x) / rect.width).clamp(0.0, 1.0);
                    let norm_y = ((point.y - rect.y) / rect.height).clamp(0.0, 1.0);
                    return Some((node, norm_x, norm_y));
                }
            }
        }
    }

    None
}
```

```rust
fn event_pass_pointer_down(&mut self, point: LogicalPoint) {
    let result = self
        .retained
        .as_ref()
        .and_then(|t| t.root.as_ref())
        .and_then(|root| hit_test_pointer_down(root, &self.layout_map, point));

    if let Some((node, norm_x, norm_y)) = result {
        let taffy_id = node.taffy_id;
        if let Some(handler) = node.handlers.on_pointer_down.clone() {
            handler(norm_x, norm_y);
            self.layout_dirty = true;
            self.paint_dirty = true;
        }
        self.mouse_capture_node = taffy_id;
    }
}

fn event_pass_pointer_move(&mut self, point: LogicalPoint) {
    let Some(capture_id) = self.mouse_capture_node else {
        return;
    };

    let handler_and_norm = self
        .retained
        .as_ref()
        .and_then(|t| t.root.as_ref())
        .and_then(|root| find_node_by_taffy_id(root, capture_id))
        .and_then(|node| {
            node.handlers.on_pointer_move.as_ref().map(|h| {
                let rect = self.layout_map.get(capture_id);
                let (norm_x, norm_y) = rect.map(|r| {
                    (
                        ((point.x - r.x) / r.width).clamp(0.0, 1.0),
                        ((point.y - r.y) / r.height).clamp(0.0, 1.0),
                    )
                }).unwrap_or((0.0, 0.0));
                (h.clone(), norm_x, norm_y)
            })
        });

    if let Some((handler, norm_x, norm_y)) = handler_and_norm {
        handler(norm_x, norm_y);
        self.layout_dirty = true;
        self.paint_dirty = true;
    }
}

fn event_pass_click_outside(&mut self, point: LogicalPoint) {
    let mut nodes_with_handler: Vec<(taffy::NodeId, Rc<dyn Fn()>)> = Vec::new();

    if let Some(root) = self.retained.as_ref().and_then(|t| t.root.as_ref()) {
        let mut nodes = Vec::new();
        collect_click_outside_nodes(root, &mut nodes);
        for node in nodes {
            if let (Some(id), Some(h)) = (node.taffy_id, node.handlers.on_click_outside.clone()) {
                nodes_with_handler.push((id, h));
            }
        }
    }

    for (id, handler) in nodes_with_handler {
        let outside = self.layout_map.get(id).map(|rect| {
            point.x < rect.x
                || point.x >= rect.x + rect.width
                || point.y < rect.y
                || point.y >= rect.y + rect.height
        }).unwrap_or(true);

        if outside {
            handler();
            self.layout_dirty = true;
            self.paint_dirty = true;
        }
    }
}
```

```rust
use std::rc::Rc;
use lemon::{
    Color,
    element::Element,
    element::builders::{Box_, Column, Row, Text},
    runtime::signal::Signal,
};

pub struct Select<T: Clone + PartialEq + 'static> {
    value: Signal<T>,
    open: Signal<bool>,
    options: Vec<(T, String)>,
    on_change: Option<Rc<dyn Fn(T)>>,
    width: Option<f32>,
}

impl<T: Clone + PartialEq + 'static> Select<T> {
    pub fn new(value: Signal<T>, open: Signal<bool>) -> Self {
        Select {
            value,
            open,
            options: Vec::new(),
            on_change: None,
            width: None,
        }
    }

    pub fn option(mut self, label: &str, value: T) -> Self {
        self.options.push((value, label.to_string()));
        self
    }

    pub fn on_change(mut self, f: impl Fn(T) + 'static) -> Self {
        self.on_change = Some(Rc::new(f));
        self
    }

    pub fn width(mut self, w: f32) -> Self {
        self.width = Some(w);
        self
    }

    pub fn into_element(self) -> Element {
        let is_open = self.open.get();
        let current_val = self.value.get();

        // Find label for current value.
        let current_label = self.options.iter()
            .find(|(v, _)| v == &current_val)
            .map(|(_, l)| l.clone())
            .unwrap_or_default();

        let open_clone = self.open.clone();
        let chevron = if is_open { "▲" } else { "▼" };

        // Trigger box.
        let mut trigger = Box_::new()
            .padding(8.0)
            .border(Color::rgb8(90, 90, 110), 1.0)
            .radius(4.0)
            .on_click(move || {
                open_clone.set(!open_clone.get());
            });

        if let Some(w) = self.width {
            trigger = trigger.width(w);
        }

        let trigger = trigger.child(
            Row::new()
                .gap(8.0)
                .child(Text::new(current_label).flex_grow(1.0))
                .child(Text::new(chevron))
        );

        if !is_open {
            return trigger.into_element();
        }

        // When open: column with trigger + dropdown.
        let open_ref = self.open.clone();
        let mut dropdown = Box_::new()
            .border(Color::rgb8(90, 90, 110), 1.0)
            .radius(4.0)
            .z_index(100)
            .on_click_outside(move || {
                open_ref.set(false);
            });

        if let Some(w) = self.width {
            dropdown = dropdown.width(w);
        }

        let mut option_col = Column::new();
        for (opt_val, opt_label) in self.options {
            let val = self.value.clone();
            let open = self.open.clone();
            let on_change = self.on_change.clone();
            let opt_val_for_click = opt_val.clone();
            let is_selected = opt_val == current_val;

            let bg = if is_selected {
                Color::rgb8(50, 80, 160)
            } else {
                Color::rgb8(30, 30, 42)
            };

            option_col = option_col.child(
                Box_::new()
                    .padding(8.0)
                    .background(bg)
                    .on_hover_enter({
                        // Note: hover visual requires Signal<bool> per-item or
                        // re-render on hover — for V0.4 we skip per-item hover
                        // and rely on the selected color only.
                        || {}
                    })
                    .on_click(move || {
                        val.set(opt_val_for_click.clone());
                        open.set(false);
                        if let Some(cb) = &on_change {
                            cb(opt_val_for_click.clone());
                        }
                    })
                    .child(Text::new(opt_label))
            );
        }

        let dropdown = dropdown.child(option_col);

        Column::new()
            .child(trigger)
            .child(dropdown)
            .into_element()
    }
}

impl<T: Clone + PartialEq + 'static> From<Select<T>> for Element {
    fn from(s: Select<T>) -> Self {
        s.into_element()
    }
}
```

```rust
use std::rc::Rc;
use lemon::{
    Color,
    element::builders::{Box_, Row},
    element::Element,
    element::style::Align,
    runtime::signal::Signal,
};

pub struct Slider {
    value: Signal<f32>,
    min: f32,
    max: f32,
    on_change: Option<Rc<dyn Fn(f32)>>,
    width: Option<f32>,
}

impl Slider {
    pub fn new(value: Signal<f32>) -> Self {
        Slider {
            value,
            min: 0.0,
            max: 1.0,
            on_change: None,
            width: None,
        }
    }

    pub fn min(mut self, v: f32) -> Self {
        self.min = v;
        self
    }

    pub fn max(mut self, v: f32) -> Self {
        self.max = v;
        self
    }

    pub fn width(mut self, w: f32) -> Self {
        self.width = Some(w);
        self
    }

    pub fn on_change(mut self, f: impl Fn(f32) + 'static) -> Self {
        self.on_change = Some(Rc::new(f));
        self
    }

    pub fn into_element(self) -> Element {
        let track_w = self.width.unwrap_or(200.0);
        let current = self.value.get().clamp(self.min, self.max);
        let frac = if (self.max - self.min).abs() < f32::EPSILON {
            0.0
        } else {
            (current - self.min) / (self.max - self.min)
        };

        // Left fill width: frac of track, leaving 16px for thumb.
        let fill_w = ((frac * track_w) - 8.0).max(0.0);

        let accent = Color::rgb8(80, 130, 230);
        let track_bg = Color::rgb8(55, 55, 75);

        // Clone signals for closures.
        let val_down = self.value.clone();
        let min_down = self.min;
        let max_down = self.max;
        let cb_down = self.on_change.clone();

        let val_move = self.value.clone();
        let min_move = self.min;
        let max_move = self.max;
        let cb_move = self.on_change.clone();

        let update = |val: &Signal<f32>, cb: &Option<Rc<dyn Fn(f32)>>, min: f32, max: f32, frac_x: f32| {
            let new_val = (min + (max - min) * frac_x).clamp(min, max);
            val.set(new_val);
            if let Some(f) = cb {
                f(new_val);
            }
        };

        // Track row: [left-fill | thumb | right-fill]
        Row::new()
            .width(track_w)
            .height(16.0)
            .align_items(Align::Center)
            .on_pointer_down(move |frac_x, _| {
                let new_val = (min_down + (max_down - min_down) * frac_x).clamp(min_down, max_down);
                val_down.set(new_val);
                if let Some(f) = &cb_down { f(new_val); }
            })
            .on_pointer_move(move |frac_x, _| {
                let new_val = (min_move + (max_move - min_move) * frac_x).clamp(min_move, max_move);
                val_move.set(new_val);
                if let Some(f) = &cb_move { f(new_val); }
            })
            // Left fill (tracks progress)
            .child(
                Box_::new()
                    .width(fill_w)
                    .height(4.0)
                    .radius(2.0)
                    .background(accent)
            )
            // Thumb circle
            .child(
                Box_::new()
                    .width(16.0)
                    .height(16.0)
                    .radius(8.0)
                    .background(accent)
            )
            // Right fill (remaining track)
            .child(
                Box_::new()
                    .flex_grow(1.0)
                    .height(4.0)
                    .radius(2.0)
                    .background(track_bg)
            )
            .into_element()
    }
}

impl From<Slider> for Element {
    fn from(s: Slider) -> Self {
        s.into_element()
    }
}
```

```rust
use std::rc::Rc;
use lemon::{
    Color,
    element::builders::{Box_, Row},
    element::Element,
    element::style::Overflow,
    runtime::signal::Signal,
};

pub struct Scroll {
    child: Element,
    offset: Signal<f64>,
    height: f32,
    width: Option<f32>,
    content_height: Option<Signal<f32>>,
}

impl Scroll {
    pub fn new(child: impl Into<Element>, offset: Signal<f64>) -> Self {
        Scroll {
            child: child.into(),
            offset,
            height: 200.0,
            width: None,
            content_height: None,
        }
    }

    pub fn height(mut self, h: f32) -> Self {
        self.height = h;
        self
    }

    pub fn width(mut self, w: f32) -> Self {
        self.width = Some(w);
        self
    }

    /// Provide the content's total height so a proportional scrollbar can be rendered.
    /// If not provided, no scrollbar is shown.
    pub fn content_height(mut self, h: Signal<f32>) -> Self {
        self.content_height = Some(h);
        self
    }

    pub fn into_element(self) -> Element {
        let viewport_h = self.height;
        let offset_val = self.offset.get() as f32;
        let off = self.offset.clone();

        // Content box with negative margin_top for scroll offset.
        let content_box = Box_::new()
            .margin_top(-offset_val)
            .child(self.child);

        // Build the scrollbar if content_height is known.
        let scrollbar: Option<Element> = self.content_height.as_ref().map(|ch_sig| {
            let content_h = ch_sig.get();
            if content_h <= viewport_h {
                return Element::None;
            }
            // Thumb height proportional to viewport / content.
            let thumb_h = (viewport_h * viewport_h / content_h).max(20.0);
            // Thumb Y position proportional to offset.
            let max_offset = (content_h - viewport_h).max(1.0);
            let thumb_y = (offset_val / max_offset) * (viewport_h - thumb_h);

            let off_drag = off.clone();
            let max_off = max_offset as f64;

            // Scrollbar track (right side, z_index: 1).
            Box_::new()
                .width(6.0)
                .height(viewport_h)
                .z_index(1)
                .background(Color::rgb8(30, 30, 42))
                .radius(3.0)
                // Thumb inside track.
                .child(
                    Box_::new()
                        .width(6.0)
                        .height(thumb_h)
                        .margin_top(thumb_y)
                        .background(Color::rgb8(100, 100, 130))
                        .radius(3.0)
                        .on_pointer_move(move |_, frac_y| {
                            let new_offset = (frac_y as f64 * max_off).clamp(0.0, max_off);
                            off_drag.set(new_offset);
                        })
                )
                .into_element()
        });

        // Viewport with content + scrollbar side by side.
        let mut viewport = Box_::new()
            .height(viewport_h)
            .overflow(Overflow::Hidden)
            .on_scroll(move |delta| {
                let new_val = (off.get() + delta).max(0.0);
                off.set(new_val);
            });

        if let Some(w) = self.width {
            viewport = viewport.width(w);
        }

        viewport = viewport.child(content_box);

        if let Some(sb) = scrollbar {
            if !matches!(sb, Element::None) {
                viewport = viewport.child(sb);
            }
        }

        viewport.into_element()
    }
}

impl From<Scroll> for Element {
    fn from(s: Scroll) -> Self {
        s.into_element()
    }
}
```

> **Note:** The scrollbar is placed as a sibling of the content inside the viewport. For it to visually overlay the content, it would need absolute positioning (not yet available). In V0.4, the scrollbar appears to the right of the content within the flex row. Proper overlay positioning is deferred to V0.5.

```rust
use lemon::{run, Color, Cx, WindowConfig};
use lemon_widgets::{Button, Column, Row, Scroll, Select, Slider, Text};

#[derive(Clone, PartialEq)]
enum Category {
    All,
    Fruits,
    Vegetables,
}

impl Category {
    fn label(&self) -> &str {
        match self {
            Category::All => "All",
            Category::Fruits => "Fruits",
            Category::Vegetables => "Vegetables",
        }
    }
}

fn all_items() -> Vec<(&'static str, Category)> {
    vec![
        ("Apple", Category::Fruits),
        ("Banana", Category::Fruits),
        ("Carrot", Category::Vegetables),
        ("Broccoli", Category::Vegetables),
        ("Grape", Category::Fruits),
        ("Spinach", Category::Vegetables),
        ("Orange", Category::Fruits),
        ("Kale", Category::Vegetables),
    ]
}

fn app(cx: &Cx) -> lemon::element::Element {
    let category = cx.use_signal(Category::All);
    let cat_open = cx.use_signal(false);
    let quantity = cx.use_signal(1.0f32);
    let scroll_offset = cx.use_signal(0.0f64);

    let cat_read = category.clone();
    let qty_read = quantity.clone();

    let items: Vec<&str> = all_items()
        .iter()
        .filter(|(_, cat)| {
            let selected = cat_read.get();
            matches!(selected, Category::All) || cat == &selected
        })
        .map(|(name, _)| *name)
        .collect();

    let item_count = items.len();

    Column::new()
        .padding(24.0)
        .gap(16.0)
        .child(Text::new("Rich Content Demo").font_size(22.0))
        // Category selector
        .child(
            Row::new()
                .gap(12.0)
                .align_items(lemon::element::style::Align::Center)
                .child(Text::new("Category:").font_size(14.0).color(Color::rgb8(160, 160, 180)))
                .child(
                    Select::new(category, cat_open)
                        .option(Category::All.label(), Category::All)
                        .option(Category::Fruits.label(), Category::Fruits)
                        .option(Category::Vegetables.label(), Category::Vegetables)
                        .width(160.0)
                )
        )
        // Quantity slider
        .child(
            Row::new()
                .gap(12.0)
                .align_items(lemon::element::style::Align::Center)
                .child(Text::new("Qty:").font_size(14.0).color(Color::rgb8(160, 160, 180)))
                .child(Slider::new(quantity).min(1.0).max(10.0).width(180.0))
                .child(
                    Text::new(move || format!("{:.0}", qty_read.get()))
                        .font_size(14.0)
                )
        )
        // Results header
        .child(
            Text::new(move || format!("{} items", item_count))
                .font_size(13.0)
                .color(Color::rgb8(140, 140, 160))
        )
        // Scrollable results list
        .child(
            Scroll::new(
                items.iter().fold(Column::new().gap(6.0), |col, name| {
                    col.child(
                        lemon::element::builders::Box_::new()
                            .padding(10.0)
                            .background(Color::rgb8(30, 30, 42))
                            .radius(6.0)
                            .width(280.0)
                            .child(Text::new(*name).font_size(14.0))
                    )
                }).into_element(),
                scroll_offset,
            )
            .height(240.0)
            .width(300.0)
        )
        .into_element()
}

fn main() {
    run(
        WindowConfig::default().title("Lemon Rich Demo").size(500.0, 600.0),
        app,
    );
}
```
